# Artificial Intelligent Virtual Assistant

This repository contains the implementation of an AI-powered Virtual Assistant. The project is specifically designed to leverage **Llama** models and will be augmented with custom knowledge and data.

## Overview
This project is based on the objectives outlined in the project proposal (`annotated-project_proposal_group77.pdf`). It aims to build a robust and highly capable virtual assistant using state-of-the-art Large Language Models.
